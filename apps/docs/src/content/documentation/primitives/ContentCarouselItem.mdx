`ContentCarouselItem` wraps arbitrary slide content (images, text, buttons, or other blocks) in a `Container` and tags it with the `carousel-item` class the `ContentCarousel` block relies on to detect slides passed via its default slot. It's only needed when slotting custom content — carousels built from the `items` array prop render their own slides automatically.
