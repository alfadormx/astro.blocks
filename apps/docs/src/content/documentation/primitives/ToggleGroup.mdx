## Listening to `selection:change`

ToggleGroup is a `single` selection group, so a subscriber sees the same payload it would get from a single-mode ItemsGrid. Both instances below publish to one selection group, so choosing in either updates the other. Instance B marks no option as selected, so it does not clear A's selection when it connects. The two textures can share a group.

## Props

`appearance` is `'radio'` (default) or `'cell'`; a cell also takes `variant`: `'solid'` (default), `'outline'` or `'ghost'`. Option presentation is layered in order: internal defaults, `defaultOptionConfig`, `selectedOptionConfig` (selected state only), the option itself, then `disabledOptionConfig` (disabled options only). One of `label` / `labelledBy` is required; `labelledBy` wins. Invalid configurations throw at build time.
