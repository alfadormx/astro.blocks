## Continuous autoplay

`autoplay: { mode: 'continuous', speed }` drifts the track at `speed` pixels per second (default 40) instead of stepping. It requires `loop`, pauses on hover, focus and the pause button, and does not start with reduced motion. Prev and next snap to the nearest slide in that direction.

## Usage notes

### Props

- `items`: Array of CarouselItem objects (optional if using slot)
- `itemClass`: Tailwind classes for slide sizing (default: `basis-full`)
- `controlsPosition`: `'inside'` (overlay) or `'outside'` (adjacent)
- Hide prev/next with `prevButton={false}` / `nextButton={false}`; indicators with `showIndicators={false}`
- `draggable`: Enable/disable pointer drag navigation (default: `true`)
- `loop`: Enable infinite looping (default: `false`)
- `autoplay`: Boolean, number (delay in ms), or config object; set `mode: 'continuous'` with `loop` for a smooth drift at `speed` px/s
- `snapFallback`: `'transform'` (default) or `'scroll-snap'`

### Accessibility

- Screen reader announcements for slide changes
- ARIA labels and roles for carousel structure
- Respects `prefers-reduced-motion` for autoplay

### Keyboard

- The indicators are one Tab stop. Left/Right arrows move to the previous or next slide, and Home/End to the first or last; focus follows the active indicator.
- The same keys work while the previous or next button has focus. When a button hides at the first or last slide, focus moves to the active indicator.
- In RTL, Left and Right swap.
- With `controlsPosition: 'inside'`, the overlay controls show while anything inside the carousel has focus, as they do on hover.

### Responsive sizing

Use Tailwind's `basis-*` utilities in `itemClass` for responsive layouts:

- `basis-full`: One slide at a time (default)
- `basis-1/2 md:basis-1/3`: Two slides on mobile, three on tablet+
- `basis-full sm:basis-1/2 lg:basis-1/4`: Progressively show more slides
