## Grid

On a list page, `renderList` returns `entries` and `page`. Each entry carries its `preset`, which picks the card. See the [blog demo](/demos/saas/blog).

<Example name="grid" source={gridSource}>
  <Grid />
</Example>

## List

`orientation: 'vertical'` stacks the cards in one column.

<Example name="list" source={listSource}>
  <List />
</Example>

## Shared card config

`defaultPostCardConfig` is merged under every post card; an entry's own values win.

<Example name="shared-config" source={sharedConfigSource}>
  <SharedConfig />
</Example>

## Pager

The pager renders when `page.lastPage` is above 1. Page 1 lives at the route, later pages at `<route>/page/<n>`.

<Example name="pager" source={pagerSource}>
  <Pager />
</Example>

## Mixed presets

Each entry picks its own card, so one list can mix presets, for example on a home page that shows the latest post, case study and event.
