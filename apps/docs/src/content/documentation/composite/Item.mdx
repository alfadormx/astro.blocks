Item renders an optional icon or image, an optional title, optional content, and action buttons, in either a vertical (stacked, centered) or horizontal (icon-left, text-right) layout. It renders only what it is given. It also supports optional connector lines, used to build timeline UIs.

## Optional Text

`title` and `content` are both optional. Item renders only what it is given — an omitted or empty value produces no element and no reserved space.

## Image Instead of Icon

`image` carries the Image primitive's configuration and renders in the same media slot as `icon`. The two are mutually exclusive — when both are supplied the image wins. `image.alt` is required at runtime; the Image primitive throws without it. Supply `width`/`height` or an `aspectRatio`, or the optimizer logs an error. The default box is `size-8 md:size-10 lg:size-12`, which fixes both axes — pass `image.class` to override it or to add `object-*` handling for a non-square source.

</Example>

## Image Size

For an image, `mediaClass` sizes a box that doesn't shrink and that the image fills, so `w-56` keeps a 224 px image next to any amount of body text. The classes also reach the `<img>`, so `aspect-*`, `object-*` and `rounded-*` apply to the picture. The image never grows past its `width`, so give it a source at least as wide as the box.

<Example name="image-size" source={imageSizeSource}>
  <ImageSize />
</Example>

## Custom Typography and Media Size

`titleClass`, `textClass` and `mediaClass` replace the default title typography, content spacing and icon or image sizes. They do not merge with the defaults, so set every class you need. `icon.class` and `image.class` still merge on top of `mediaClass`.

`title` is inline Markdown, so `**…**` renders as `<strong>` inside the title element and `titleTag` and `titleClass` still apply. Here a light caption carries one bold phrase.

## Text Tag

`textTag` sets the tag of the element styled by `textClass`. Use `'p'` only for plain or inline content: a `<p>` cannot hold block HTML such as `<p>` or `<ul>`, and the browser would break it apart.
