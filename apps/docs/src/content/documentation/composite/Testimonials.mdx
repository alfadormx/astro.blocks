## Grid

The default `layout="grid"` places cards in up to `columns` columns, stepping down as the container narrows. Blank lines in `quote` start new paragraphs.

## Rating

`rating` draws one to five stars. The stars are hidden from assistive tech; `ratingLabel` is read instead (default `'{rating} out of 5'`).

<Example name="rating" source={ratingSource}>
  <Rating />
</Example>

## Avatar and source

`author.avatar` takes Image props and renders a small round photo. `source` adds a cited link to the original review.

  <AvatarSource />
</Example>

## Shared config

`defaultTestimonialConfig` restyles or localizes every card, here a Spanish `ratingLabel` and the pull-quote font restored through `quoteClass`.

## Carousel

`layout="carousel"` puts one card per slide in a ContentCarousel, showing one, two or three at a time as the container widens (`slideClass`). Configure the carousel through `contentCarousel`. With more than one card per view, set `loop`: without it, the last positions leave empty space. Without JavaScript only the first cards show.
