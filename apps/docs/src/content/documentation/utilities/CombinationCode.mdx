A combination code captures the selection of an ordered set of selection groups in one string. `connectUrlState` keeps it in the `?code=` query parameter: a shared link opens on the same configuration, and back and forward walk through earlier ones.

## Demo

Change the options below and watch the address bar. Try [Gold with Insurance, Express and an engraving](?code=RING01-GD-IN.EX-Hello%20you) or [a stale code](?code=RING01-XX-IN.ZZ-), which applies what it can and, in development, logs a `[urlState]` warning for the rest.

## Format

Groups sit in spec order, separated by `-`, after an optional product segment. Entries of a `multiple` group sit in spec option order, separated by `.`, so one configuration always yields one code. Option and product codes match `[A-Za-z0-9]+`, which keeps both separators free.

## Edge cases

Decoding is forgiving per group: whatever a stale or hand-edited code gets wrong falls back to that group's page-load default, and the rest still applies. A code may select more options than a group's `max`; limits are not enforced on decode.

## History

- Every discrete change, such as a click, pushes one history entry.
- Consecutive keystrokes in the same text group replace the current entry, so a typing burst is one entry.
- Back and forward restore each entry's configuration without writing a new entry.
- An entry without a code, such as the page as first opened, restores the page-load defaults.
- Other query parameters and the hash are preserved on every write.
- Loading a page with a code writes nothing, even when the code is not canonical. Text longer than the field's limit is truncated, and the URL is rewritten in place to match.
- Returning to the defaults still writes a code; it is never stripped.

## Append-only groups

<div class="bg-warning/10 border-l-4 border-warning p-4 rounded">

Segments are positional. Removing or reordering a group shifts every later segment, and old codes are then silently misread. Add new groups at the end only; old codes keep working because a missing trailing segment keeps its default.

</div>

## Usage

`connectUrlState({ spec, param })` is browser-only: call it from a client `<script>`. It seeds the groups on `DOMContentLoaded`, after every block's initial publish, so the code wins over block defaults. It re-runs after `astro:after-swap` and returns a function that disconnects it. `param` defaults to `'code'`.

<CodeBlock code={usage} lang="html" />

The codec is pure and safe anywhere, including frontmatter: `validateCombinationSpec` throws on an ambiguous spec, `encode` returns the code for a state, and `decode` returns the selections plus notes on what it dropped.
