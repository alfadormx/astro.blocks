Collections let you write content as Markdown files and list them with one block.

## What you get

- A typed schema per **preset**.
- A list page and an entry page, each about ten lines.
- Translations linked by filename.

> Write the content; the blocks handle the rest.

Inline `code` and [links](/documentation) are styled from the theme tokens.
