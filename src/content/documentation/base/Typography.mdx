## Headings

- **h1:** `clamp(2rem, 1.5rem + 2vw, 3rem)`, 32px → 48px, line height 1.2
- **h2:** `clamp(1.75rem, 1.5rem + 1.25vw, 2.25rem)`, 28px → 36px, line height 1.25
- **h3:** `clamp(1.5rem, 1.35rem + 0.75vw, 1.875rem)`, 24px → 30px, line height 1.3
- **h4:** `clamp(1.25rem, 1.15rem + 0.5vw, 1.5rem)`, 20px → 24px, line height 1.3
- **h5:** `1.125rem` (fixed), 18px, line height 1.4
- **h6:** `1rem` (fixed), 16px, line height 1.4
