The Container block provides flexible layout control with support for various width configurations and rich background options.

## Container and content width

Control how your container and content are sized using `containerWidthType` and the `content` object.

- **containerWidthType**: Controls the outer container (background/section) width.
- **content.widthType**: Controls the inner content width (only when containerWidthType is `full`).
- **content.boxWidth**: Custom max-width for boxed content (default: `max-w-[var(--container-max-width)]`).
