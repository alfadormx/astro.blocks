Every modal needs an `id` that is unique on the page: triggers find it by id, and the docs layout already uses `docs-menu`.

## Usage

Open a modal with `data-modal-trigger` set to its `id`, on any element:

```astro
<Button data-modal-trigger="my-modal" label="Open" />
<Modal id="my-modal">…</Modal>
```

Close it with `data-modal-close` on any element inside it:

```astro
<Button data-modal-close label="Close" />
```
