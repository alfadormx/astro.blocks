## Basic

Pass the source as `code` and a Shiki language id as `lang`. The copy button copies the rendered text, so Windows line endings (`\r\n`) are copied as `\n`.

<Example name="basic" source={basicSource}>
  <Basic />
</Example>

## Title

A `title` renders as a filename caption, with the copy button beside it.

<Example name="title" source={titleSource}>
  <Title />
</Example>

## No copy button

Set `copyButton` to `false` to hide the button.

<Example name="no-copy" source={noCopySource}>
  <NoCopy />
</Example>

## Long lines

Long lines scroll inside the block, never the page. The code area is keyboard-focusable, so the arrow keys scroll it.

<Example name="long-lines" source={longLinesSource}>
  <LongLines />
</Example>

## Token colours

The block uses GitHub's light and dark themes and follows the site theme toggle. MDX fenced code blocks use the same themes.

<Example name="tokens" source={tokensSource}>
  <Tokens />
</Example>

## Escaping

The source renders as text, so markup is shown, not interpreted.

</Example>
