The Vector component renders SVG files inline, allowing them to inherit colors from CSS text color classes. Perfect for logos, icons, and illustrations that need to adapt to different color schemes.

## Responsive layout (default)

SVG scales to fit container width and inherits text color via `currentColor`.

<Example name="responsive" source={responsiveSource}>
  <Responsive />
</Example>

## Color inheritance

The Vector component uses `currentColor` to inherit from text color classes.

  <ColorInheritance />
</Example>

Use fixed layout with explicit width and height for precise dimensions.

## Alignment

Control horizontal alignment with the `align` prop: left, center, or right.

  <Alignment />

## Fill layout

SVG fills the entire container dimensions. Useful for background graphics.

  <Fill />

Use `preserveColors` to keep the SVG's original colors instead of applying `currentColor`.
