## Basic

Each item is a `<details>`. Click a title, or focus it and press Enter or Space, to toggle it. Several items can be open at once.

Titles render in a `span` by default. Set `titleTag` to a heading level when the titles belong in the page outline, as in an FAQ section.

</Example>

## Single

`mode="single"` gives every item the same `name`, so the browser closes the open item when another opens. No JavaScript involved.

## Rich content from slots

An `item-N` slot (0-based) replaces that item's `content`. Keep slotted answers to static markup.

## Nested

An Accordion can sit inside another's slot. Each chevron follows its own item, so an inner item stays closed and unrotated while its parent is open.
