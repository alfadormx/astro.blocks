The Map component renders a fully interactive map using [Leaflet.js](https://leafletjs.com) and OpenStreetMap tiles. No API key is ever required. Supports markers with optional popup labels, three free tile layers, and fully configurable dimensions.

Leaflet and its tiles load only when a map comes within 200px of the viewport. Once a map is ready, the block sets `data-map-ready`. A map inside a hidden or zero-size container (a closed modal, a collapsed accordion) never intersects, so it doesn't load until it's shown.

## Default — marker at location (Paris)

Provide `lat` and `lon`. A marker is placed at the given coordinates by default. `zoom` defaults to `13`.
