## Path preservation

By default each button keeps the current path, so `/pricing` links to `/es/pricing`. Pages that exist in one language only should pass `preservePath={false}` so every button links to that language's `basePath`. The demos on this page do, because documentation is English-only.

</Example>

## Usage in context

The Language Toggle component automatically detects the current language from the URL path and highlights the active language button. The buttons below link to each language's home page, because the documentation is not translated.
