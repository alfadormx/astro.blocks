## Notes

`vector` takes precedence over `image` — when both have a `src`, only the vector renders. Setting either one suppresses the default site-name label.

Logo renders its `vector` or `image` into the Button slot, so neither is forwarded to the Button's own `icon` / `image` media slot. Every other prop is passed through to the Button primitive, so `variant`, `intent`, `size`, `href` and `class` behave exactly as they do there.
