## Vertical orientation

The `orientation` prop stacks the icon or image above the label. It has no literal default: without it, a button resolves to vertical only when a `subtitle` is set. An explicit value always wins.

<Example name="vertical" source={verticalSource}>
  <Vertical />
</Example>

## With images

`icon` and `image` occupy the same media slot and are mutually exclusive; when both are supplied the image wins. `iconPosition` positions whichever medium is present. `image.alt` is required at runtime — the Image primitive throws without it.

<Example name="images" source={imagesSource}>
  <Images />
</Example>

## Image sizing

`imageSize` is a Tailwind class governing the rendered box, while `image.width` / `image.height` / `image.aspectRatio` govern what the optimizer generates. Both are needed — supply dimensions or an `aspectRatio`, or the optimizer logs an error. Note that `image.layout` of `'cover'` or `'contained'` makes the Image wrapper `w-full h-full`, which will fill the button.
