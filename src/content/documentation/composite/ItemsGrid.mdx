ItemsGrid sizes its columns from the width of the element that contains it, not from the viewport. A grid asks for at most `columns` columns and, by default, steps down when its container is too narrow to fit them: two columns from `32rem`, three from `48rem`, four from `64rem`. The same grid therefore renders three columns in a full-width section and one in a sidebar, with no change at the call site. Set `responsive={false}` to keep `columns` at any width (see _Fixed columns_).

## Single selection

With `selection={{ mode: 'single', group, label }}` every item becomes an option. Each item needs a `code`, the value published to the group; `selected: true` marks the option chosen on load. Options cannot carry `actions`.

<Example name="single-selection" source={singleSelectionSource}>
  <SingleSelection />
</Example>

## Multiple selection with min and max

`mode: 'multiple'` turns each option into a checkbox. `max` disables the remaining options once reached; `min` refuses a deselect that would drop below it. An initial state below `min` is allowed — nothing is selected implicitly.

## Listening to selection:change

The grid publishes to the selection runtime; anything on the page can read it with `subscribe(group, listener)` or a `selection:change` listener on `document`. Other publishers to the same group update the grid too — the button below sits outside the grid, in its own element declaring the same group.

`fillLastRow` stretches a lone item in the last row across the full row. It is computed from `columns`, so it is exact only together with `responsive={false}`.

## Selection props

`selection` is an `ItemsGridSelection`: `{ mode: 'none' }` (default, a static grid with no roles or script), `{ mode: 'single', group, label?, labelledBy?, intent? }`, or `{ mode: 'multiple', group, label?, labelledBy?, min?, max?, intent? }`. One of `label` / `labelledBy` is required; `labelledBy` wins. Items are `ItemsGridItem`s — Item props plus `code` (required when selection is enabled, unique within the grid) and `selected` (initial state). Invalid configurations throw at build time.
