## Upcoming

Times show in `timezone`, with the zone name. On a collection page the helpers pass the event’s own zone, else `collections.timezone` from `config.yaml`.

## Past

`past` adds the badge. The page helpers set it at build time, so a static site needs a scheduled rebuild to move events into the past.
