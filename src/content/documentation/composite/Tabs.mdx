## Tab list layout: grid

`tabList.layout: 'grid'` arranges the triggers as tiles. The column count is read from the width of the tab list's own container, not the viewport, so the same config adapts inside a narrow panel. `tabList.columns` applies only in this layout, and the count never drops below two columns. Each tile fills its grid cell, so every tile has the same size.

Grid is meant for `orientation="horizontal"`. In `orientation="vertical"` the tab list sits in an `auto` grid track, where a size container has no intrinsic width to measure, so the tile grid collapses; use `layout: 'row'` or `layout: 'column'` there.

## Sticky tab list

`tabList.sticky` keeps the triggers in view while the panels scroll. Under a sticky Header the tab list stops directly below it: Header publishes its height as `--scroll-padding-top` and the tab list's default `top` reads it, falling back to `0` when no Header is sticky. The box below is its own scroll box under the docs page's sticky Header, so it cancels the offset with `top-0`; scroll it and the triggers stay at the top.

The flag adds `sticky top-(--scroll-padding-top,0px) z-10 bg-background`, plus `self-start` in vertical orientation. In grid layout they land on the `@container` wrapper, so cancel them from `tabList.wrapperClass`; in row and column layouts they land on the tab list, so cancel them from `tabList.class`. Use `top-0` when the tabs sit in their own scroll box under a page-level sticky Header (`md:top-0` if that box only exists from a breakpoint up), and swap `bg-background` for the section's background, such as `bg-surface`, to avoid a visible band.

## Accessibility

- The tab list is a single tab stop: `Tab` lands on the active tab and leaves to the panel content.
- Arrow keys follow the tab list's axis: Left/Right for `row` and `grid` layouts, Up/Down for `column`. Left/Right are swapped in right-to-left documents.
- Home and End jump to the first and last tab.
- Focus wraps at both ends, and moving focus activates the tab.
- Disabled tabs are skipped.
- The layout sets `aria-orientation` on the tab list; grid layouts are navigated as a single row in reading order.
