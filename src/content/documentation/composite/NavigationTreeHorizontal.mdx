## Current page

The item whose `href` matches `currentPath` (default: the page URL) gets `aria-current="page"` and `activeItemConfig`; the rest get `inactiveItemConfig`. Matching is exact, so a hash link such as `/#pricing` is never current. A parent is not marked for a current child, and a click-mode parent, being a button, keeps the look without `aria-current`.

## Usage notes

**Structure.** Each item in the `items` array follows the ButtonProps interface. Items with a `children` array render as dropdown menus.

**Trigger modes.** Hover: dropdowns appear on mouse hover (best for desktop). Click: dropdowns appear on click and close when clicking outside or pressing Escape (better for touch devices).

**Depth limitation.** This component is designed for 1–2 levels (parent → children). For deeply nested navigation, use the vertical NavigationTree component instead.
