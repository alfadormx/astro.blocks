## Basic

The date and reading time sit above the title. On a collection page, `CollectionList` builds these props from each entry, so you rarely write them by hand.

## Without a cover

## Language

`langCode` picks the date format and the UI strings. Spanish ships with the library; other languages fall back to English, and `readMoreLabel` overrides the text.
