## Expansion strategies

### Always expanded

All children visible at all times.

<Example name="always-expanded" source={alwaysExpandedSource}>
  <AlwaysExpanded />
</Example>

### Active only (default)

Only shows children of active items.

<Example name="active-only" source={activeOnlySource}>
  <ActiveOnly />
</Example>

### First level only

Shows only root-level items, no children.

<Example name="first-level" source={firstLevelSource}>
  <FirstLevel />
</Example>

### Depth limited (`maxDepth={1}`)

Expands children up to the specified depth.

<Example name="max-depth" source={maxDepthSource}>
  <MaxDepth />
</Example>

### Toggleable (interactive)

Click parent items to expand or collapse children. The active path is expanded automatically.

<Example name="toggleable" source={toggleableSource}>
  <Toggleable />
</Example>

## Toggle modes

### Button toggle (default, mobile-friendly)

The entire button toggles children. Good for touch devices with larger tap targets.

<Example name="button-toggle" source={buttonToggleSource}>
  <ButtonToggle />
</Example>

### Icon toggle only

Only the icon toggles children; the button navigates to its `href`. This provides separate controls for navigation and expansion.

<Example name="icon-toggle" source={iconToggleSource}>
  <IconToggle />
</Example>

### Default item styling

Default-config `class` and `icon` reach every item.

`defaultItemConfig` reaches every item; `inactiveItemConfig` / `activeItemConfig` layer on top.

Parents keep the `iconName` chevron over the default icon.

<Example name="default-config" source={defaultConfigSource}>
  <DefaultConfig />
</Example>

### Active item weight

The active item is semi-bold by default. `activeItemConfig.class` can change its weight.

<Example name="active-weight" source={activeWeightSource}>
  <ActiveWeight />
</Example>

### Children wrapper

`childrenClass` styles the wrapper around every level of children, here a guide line as in a docs sidebar.

<Example name="children-class" source={childrenClassSource}>
  <ChildrenClass />
</Example>

## Current path detection

Without `currentPath`, the tree matches against the page URL.

<Example name="current-path" source={currentPathSource}>
  <CurrentPath />
</Example>

The active link carries `aria-current="page"`; a parent rendered as a `<summary>` toggle keeps the active look without it.
