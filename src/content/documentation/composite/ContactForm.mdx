## Basic

The default fields post to an endpoint such as Formspree or Basin. Without JavaScript the form posts natively; with it, success and error show inline and take focus. The hidden `_gotcha` field follows Formspree’s spam-trap convention; set `honeypot` to the name your provider drops, or `false`.

</Example>

## Custom fields

`fields` takes any form primitive, tagged by `control`. A provided list replaces the defaults.

## Mailto

No service is needed: the visitor’s mail app opens with the message filled in. Without JavaScript the browser falls back to a native `text/plain` mailto post.
