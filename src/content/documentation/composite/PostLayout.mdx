## Basic

On an entry page, `renderEntry` returns these props as `layout` and the rendered Markdown as `Content`, which goes in the default slot. The body uses the `prose` class from `@tailwindcss/typography`, coloured from the theme tokens, so it follows light and dark mode.

<Example name="basic" source={basicSource}>
  <Basic />
</Example>

## Body width

`bodyClass` merges after `prose`, so typography modifiers apply: here `max-w-none` lets the text use the full width, and `prose-lg` would enlarge it.
